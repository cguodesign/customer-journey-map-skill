### Step: wait-in-silence
- persona: [Maya, Recruiter, Hiring Manager, ATS]
- emotion: Hope curdling into anxiety, then resignation
- emotionValence: -2
- waitTime: Days to several weeks, often indefinite
- handoff: Recruiter → Hiring Manager for shortlist review
- bottleneck: Hiring Manager review capacity
- lineOfVisibility: Status changes exist inside the ATS and are never exposed
- momentOfTruth: This silence is the make-or-break of the whole experience

Theming

Your colours are four values, not a rewrite.

Renderings hold no literal colours — only token names. Re-seed the top tier and the whole palette re-derives: lane tints, the valence scale, rules, shadows, dark mode. Semantic colours deliberately stay put, because a moment of truth marker that repaints itself when your logo changes isn't a marker.

This one is live. Use the switch in its top-right corner — that's a real rendering, not a picture of one.

# your brand
journey.sh theme map.html --primary '#6C2BD9' --surface '#fff' --text '#1a1320'

# or one of the presets
journey.sh theme map.html --preset paper  # paper · midnight · blueprint · contrast
Why it's different

A Figma file vs. a living map.

A static map

  • Beautiful the week it's made
  • Stale by the next sprint
  • Re-drawn from scratch when things change
  • One format, one audience
  • Lives in a file nobody reopens

Journey

  • Built from a conversation
  • Updated by diff as you learn
  • Persists and grows across sessions
  • Renders for any audience on demand
  • Knows evidence from guesswork
FAQ

Your questions, answered.

Do I need to be technical to use it?

No. You talk; it writes the structure. You never touch the schema, a form, or a diagram tool.

Does it need npm or a build step?

No. It's a Claude Code skill — pure markdown and static templates, zero runtime dependencies. You install it by cloning into your skills folder.

Where do my maps get saved?

To ./.journey/<name>.md in your project — a plain markdown file you own. No storage? It works entirely in the conversation and hands the map back to you to save.

Can my team share one map?

Today it's tuned for an individual building deep, durable understanding. Shared, multi-contributor maps (Notion/Drive) are on the roadmap.

What does it cost?

It's open source under MIT. You bring Claude Code.
