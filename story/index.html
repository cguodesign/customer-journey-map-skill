04 / 修正方向

给 agent 一张地图。

git clone --depth 1 https://github.com/cguodesign/customer-journey-map-skill ~/.claude/skills/journey

Journey Skill 把人的体验与观察、修改和依据连在一起。

「改成推门即用。」

$ journey.sh commit … remove-step book-ahead
ERROR … dangling cross-ref: → book-ahead
commit rejected (no changes written)

改坏的地图，存不进去。

$ journey.sh commit … replace-step find-room
committed replace-step find-room on meeting-room — logged …
$ journey.sh validate meeting-room
OK: meeting-room (4 steps, 3 milestones)

推门即用，
写进了地图。

validate 只查结构和引用。对人好不好，还要你来判断。

05 / 让证据说话

「还是加个签到吧。」

多一步，为什么？

$ journey.sh query moment-no-evidence
check-in  momentOfTruth without source/metric

这一步能存进去。查询会列出它缺什么。

没有证据。
你们决定撤回。

$ journey.sh commit … remove-step check-in
committed remove-step check-in on meeting-room — logged …

查询只负责列出来，撤不撤由你们定。撤回的理由写进修改记录。
