模板是怎么做出来的？

  1. 从旅程数据出发

    告诉 agent 读哪份 .journey/*.md、给谁看、希望对方做什么。已有字段决定内容，缺失信息保留为空。

  2. 组合布局与交互

    agent 读取 rendering 模板的结构，再结合 interaction 模板的行为和 wireframe 参考，生成独立 HTML。模板可以按用途扩展。

  3. 用 theme 命令统一配色

    生成的组件使用语义颜色 token。theme 命令安装颜色体系，再用预设替换基础色，整张图自动派生。

哪些是命令，哪些是对话？
journey.sh theme 是确定性命令：安装 token、应用预设、设置基础色。生成布局和制作模板属于 Express 模式，由 agent 完成；目前没有 journey.sh render 或 template create 命令。
# 在 skill 目录下运行；map.html 指向你的输出文件
bash scripts/journey.sh theme map.html --init
bash scripts/journey.sh theme map.html --preset paper
bash scripts/journey.sh theme map.html --primary '#bac4ae' --surface '#090a0a' --text '#e7e8e2'
bash scripts/journey.sh theme map.html --clear
Graphite 是这个新版官网新增的主题文件，下载并安装后才能使用 --preset graphite；其余四套预设来自当前 skill。
