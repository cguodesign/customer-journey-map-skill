# Demo 00 — Hero: one journey, all four modes

**The flagship.** Watch a single journey get **built → expressed → updated → reviewed**
across the life of a project — the whole point of the skill in one sitting. Every mode
is detected from how you talk; you never name a command.

**Time:** ~12 min · **New session.** Produces `./.journey/job-application-portal.md`
plus an interactive HTML. This is the run captured in test report 17 (all four phases
passed; Review even caught a real structural bug it had created).

---

### Phase a — Discovery → **Build** (Plan)
```
Let's map the journey of someone applying for a job through a company's online application portal — from seeing the posting to hearing back. Build the whole arc out, I'll refine as we go. The big thing on my mind: so many people apply and just never hear anything — the "application black hole."
```
**Watch:** it scaffolds the full arc fast (Discovery → Application → The Wait →
Resolution), invents a believable persona, flags the black hole as a moment of truth,
and — at the natural pause — offers to focus and notes where it has no evidence. No
field menu, ever.

### Phase b — Evaluation → **Express** (interactive HTML)
```
Make an interactive HTML version our hiring team can pull up in a review meeting — I want them to actually see how brutal the silent wait is.
```
**Watch:** it picks a rendering + interaction mode from the data, builds a
self-contained HTML, and surfaces the options you couldn't see (theme it, dark mode,
switch the view). Open the file in a browser.

### Phase c — Development → **Update** (Modify)
```
Update the map — we just rolled out an AI resume-screening step that auto-rejects within 24 hours if you don't match. So a chunk of applicants get a fast 'no' instead of silence. But the ones who pass still fall into the same old black hole. Fold this in.
```
**Watch:** a **diff**, not a redraw — it shows what changed and why, adds the AI-screen
fork, and makes your worry (passers still hit the black hole) *structurally visible* in
the map. It won't invent a drop-off number; it flags it as a hypothesis to measure.

### Phase d — Stable → **Review**
```
Okay, this map has been through a few rounds and feels solid. Step back for me — review the whole thing: where's it still weak or thin, and what other journeys should we be mapping while we're at it?
```
**Watch:** a health review (evidence gaps, thin steps, missing recovery paths, even an
orphaned branch in the flow graph) **plus** a ranked shortlist of adjacent journeys
worth mapping (the interview journey, the recruiter's side, the wrong-rejection appeal).
It changes nothing — it proposes, and waits for you to pick.

---

✅ **What you just saw:** one living map, four gears — build, express, update, review —
each entered just by talking. The map persisted and grew across every turn. That's the
"long-term living document" promise, end to end.
